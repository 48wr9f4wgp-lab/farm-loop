# Farm Loop v0.6 Productization Wave 1

Date: 2026-08-23

## Product position
Farm Loop is not a regional agriculture simulator. It is a mobile entertainment game about growing a rich snow-country satoyama. Minami-Uonuma, wild vegetables, mushrooms, beekeeping, chickens and snow culture are the identity layer, not a constraint on fun.

## Product pillars
1. One-glance clarity: next action, reward and progress must be obvious.
2. One-tap delight: avoid repetitive single-item interactions; actions resolve quickly and clearly.
3. Visible growth: the map and village become richer as the player progresses.
4. Return reason: short recurring goals and discovery targets exist without blocking free play.
5. Snow-country identity: seasons, mountain exploration, rare finds and satoyama circulation stay distinctive.

## v0.6 scope
- Replace management-console shell with a game-first mobile HUD.
- Move exploration and chain progression above bookkeeping panels.
- Add a daily Satoyama Notebook with three lightweight goals and a completion reward.
- Improve card hierarchy, touch targets, navigation and selected-state readability.
- Add a visual polish overlay to the farm map for depth, atmosphere and progress celebration.
- Keep no-energy-lock exploration and no dead-end economy.
- Preserve v0.5 core loop and save compatibility.

## Benchmark principles refreshed 2026-08-23
- Hay Day: faster task flow, clearer help states, richer early rewards and simpler progress UI.
- Japanese Rural Life Adventure: daily quests and treasure discovery reinforce return motivation without replacing the rural-life fantasy.
- Family Island: exploration and reward-driven adventure create peaks above routine production.
- My Dear Farm: customization and visual ownership are strong; repetitive one-by-one harvesting is a friction pattern to avoid.

## Hard gates
- Japanese UI font must render in Web build.
- Import / parse / core loop / v0.5 entertainment / v0.6 product tests / UI smoke / Web export must all pass before Pages deploy.
- Physical iPhone Safari remains the final visual and audio gate.
